# Controls

All keyboard actions can be rebound in **Options → Controls** (click a binding, then press the new key; Esc cancels).
Bindings are saved with the other settings in `settings.json` in the player's persistent data folder.

## Mouse

| Input | Action |
|---|---|
| Left click | Select a unit or structure |
| Left drag | Box-select (prefers combat units over harvesters and support units) |
| Shift + left click / drag | Add to or remove from the selection |
| Double left click | Select all visible units of the same type |
| Right click | Context order: move, attack, capture, dock, repair, rearm, enter transport, guard, harvest, deploy |
| Shift + right click | Queue the order (waypoints) |
| Ctrl + right click | Force fire on a unit, structure or the ground |
| Alt + right click | Force move (ignore enemies on the way) |
| Middle drag | Pan the camera |
| Mouse wheel | Zoom (can be inverted in Options → Gameplay) |
| Screen edges | Scroll the camera (can be turned off in Options → Gameplay) |
| Minimap left click / drag | Move the camera |
| Minimap right click | Order the selection to that point |

### Sidebar

| Input | Action |
|---|---|
| Left click on a cameo | Queue one item (Shift: five). For a finished structure: start placement |
| Right click on a cameo | Put production on hold; right click again to cancel and refund |
| Placement: left click | Place the structure. Shift keeps placing walls |
| Placement: Tab | Rotate the footprint where the structure allows it |
| Placement: right click / Esc | Cancel placement |

## Keyboard (defaults)

| Key | Action |
|---|---|
| Arrow keys | Scroll the camera |
| Page Up / Page Down | Zoom in / out |
| Insert / Delete | Rotate the camera 90° |
| Home | Reset camera rotation and zoom |
| H | Jump to your base |
| Space | Jump to the latest alert |
| Ctrl + 0–9 | Assign control group |
| 0–9 | Select control group (press twice to centre on it) |
| Shift + 0–9 | Add a control group to the selection |
| Ctrl + A | Select all your units |
| Q | Select all combat units |
| W | Select all units of the selected type on screen |
| S | Stop |
| G | Guard area |
| D | Deploy (mobile HQ, transports unload, special abilities) |
| A | Attack-move (then click the destination) |
| P | Patrol (then click the destination) |
| X | Scatter |
| T | Cycle stance: Aggressive → Guard → Hold Position → Hold Fire |
| R | Repair mode (click your structures) |
| Z | Sell mode (click your structures) |
| Tab | Rotate structure during placement |
| B | Always show health bars |
| O | Objectives panel |
| = / − | Game speed up / down (skirmish) |
| Esc | Pause menu; skips the prologue cinematic and closes dialogs |
| F6 / F9 | Quick save / quick load |
| F12 | Screenshot (saved to the persistent data folder) |
